# 下一帧，请签收 · 场景 01

根据《下一帧请签收_修订剧本v2_1.md》制作的十秒视觉初稿，仅包含「第一天上班」。

- 打开 `index.html`：播放样片，可切换三个画风，暂停、重播、慢放和拖动时间轴。
- 打开 `directions.html`：比较三版画风的真实关键帧。
- `design-notes.md`：设计依据、分镜及实现约束。

纯 HTML / Canvas / SVG / JavaScript，无外部依赖，无需安装，离线可用。Canvas 绘制规则网格和街道，SVG 绘制角色、信封与建筑。地图与蓝色收件点共用旋转变换，虚线路线固定在画面坐标系中。时间轴由 `render(t)` 决定，可任意回退，不依赖播放历史。

## 时间轴

| 时间 | 动作 |
|---|---|
| 0–3 秒 | 网格展开、接信、信封与红色邮戳特写 |
| 3–5 秒 | 画出直线，出现中英文对白 |
| 5–7 秒 | 起跑、地图旋转、急刹、帽子飞出 |
| 7–10 秒 | 帽子落地、捡起并戴回；中英文旁白字幕 |

这一轮为字幕样片，未合成旁白、音乐或音效。

## 后续复用接口

URL 参数：`?look=sky&t=6.35&paused=1&clean=1`，`look` 可选 `sky` / `comic` / `future`。`clean=1` 隐藏播放器，保持 16:9 画幅。`autoplay=1` 自动播放，默认等待点击。

`window.__seek(seconds)` 暂停并定位；`window.__frameState(seconds)` 获取地图、角色和帽子的位置；`window.__ready` 表示首帧绘制完成。空格播放 / 暂停，方向键左右逐帧查看（焦点不在控件时）。
